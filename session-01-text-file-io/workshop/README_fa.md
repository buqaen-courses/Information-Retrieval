## ایستگاه اول — باز کردن فایل و شمارش محتوا

<text color="secondary" size="sm">زمان پیشنهادی: ۱۵ دقیقه</text>

در حال حاضر، تابع `count_stats()` هنوز نمی‌تواند فایل را باز کند و محتوای آن را بشمارد. ابتدا همین قابلیت پایه‌ای را پیاده‌سازی می‌کنیم؛ مهارتی که در بسیاری از بخش‌های این دوره به آن نیاز خواهید داشت.

### گام اول: فایل را باز کنید

برای باز کردن فایل متنی، از دستور زیر استفاده می‌کنیم:

```python
open(path, mode="r", encoding="utf-8")
```

در این دستور:

* `path` مسیر فایل موردنظر است.
* `mode="r"` فایل را برای خواندن باز می‌کند.
* `encoding="utf-8"` مشخص می‌کند بایت‌های فایل چگونه به متن تبدیل شوند.

خروجی `open()` یک شیء فایل است که می‌توانیم با استفاده از آن، محتوا را خط‌به‌خط بخوانیم.

### گام دوم: سه شمارنده بسازید

فایل `workshop/starter/text_stats.py` را باز کنید و بخش‌های `TODO-1` و `TODO-2` را با کد زیر جایگزین کنید:

```python
f = open(path, mode="r", encoding="utf-8")

lines = 0
words = 0
chars = 0

for line in f:
    lines = lines + 1
    words = words + len(line.split())
    chars = chars + len(line)

f.close()

return {
    "lines": lines,
    "words": words,
    "chars": chars
}
```

در این کد، سه متغیر برای نگهداری آمار فایل داریم:

* `lines`: تعداد خط‌ها
* `words`: تعداد واژه‌ها
* `chars`: تعداد نویسه‌ها

حلقهٔ `for line in f:` فایل را خط‌به‌خط پیمایش می‌کند. در هر تکرار، یک خط در اختیار برنامه قرار می‌گیرد و شمارنده‌ها به‌روزرسانی می‌شوند.

متد `split()` خط را بر اساس فاصله‌ها به بخش‌هایی تقسیم می‌کند. سپس `len()` تعداد این بخش‌ها را برمی‌گرداند. به همین ترتیب، `len(line)` تعداد نویسه‌های خط را می‌شمارد؛ این مقدار شامل نویسهٔ پایان خط نیز می‌شود، اگر آن نویسه در متن خوانده‌شده وجود داشته باشد.

در پایان، فایل را می‌بندیم و آمار را در قالب یک دیکشنری برمی‌گردانیم.

## ایستگاه دوم — شمارش واژه‌ها و پیدا کردن واژه‌های پرتکرار

<text color="secondary" size="sm">زمان پیشنهادی: ۱۵ دقیقه</text>

شمارش محتوا مفید است؛ اما برای تحلیل متن باید بتوانیم واژه‌ها را نیز بر اساس میزان تکرارشان مرتب کنیم. در این مرحله، تابع `top_words()` را کامل می‌کنیم.

این ایده در جلسات بعدی، از جمله هنگام بررسی روش‌هایی مانند TF-IDF در جلسهٔ هفتم، کاربرد خواهد داشت.

### گام اول: شمارندهٔ واژه‌ها را بسازید

مفهوم جدید این بخش، استفاده از دیکشنری برای ثبت تعداد تکرار هر واژه است.

```python
counts[word] = counts.get(word, 0) + 1
```

معنای این دستور ساده است: اگر واژه قبلاً دیده شده باشد، شمارندهٔ آن را یک واحد افزایش بده؛ در غیر این صورت، شمارش را از صفر شروع کن.

برای تکمیل تابع، بخش‌های `TODO-3` و `TODO-4` را با کد زیر جایگزین کنید:

```python
counts = {}

f = open(path, mode="r", encoding="utf-8")

for line in f:
    for raw in line.lower().split():
        word = raw.strip(".,!?;:\"'()")

        if word == "":
            continue

        if word in counts:
            counts[word] = counts[word] + 1
        else:
            counts[word] = 1

f.close()

ordered = sorted(
    counts,
    key=counts.get,
    reverse=True
)

result = []

for word in ordered[:n]:
    result.append((word, counts[word]))

return result
```

### گام دوم: متن را پیش از شمارش یکدست کنید

به این سه مرحله توجه کنید:

۱. **یکسان‌سازی حروف:** متد `lower()` حروف انگلیسی را به حروف کوچک تبدیل می‌کند. بنابراین، `Search` و `search` یکسان در نظر گرفته می‌شوند.

۲. **تقسیم متن:** متد `split()` هر خط را به بخش‌هایی تقسیم می‌کند که معمولاً واژه‌ها هستند.

۳. **حذف نشانه‌گذاری:** متد `strip(".,!?;:\"'()")` نویسه‌های مشخص‌شده را از ابتدا و انتهای هر بخش حذف می‌کند. برای مثال، `text.` به `text` تبدیل می‌شود.

اگر پس از این عملیات رشته‌ای خالی باقی بماند، دستور `continue` آن را نادیده می‌گیرد.

### گام سوم: واژه‌ها را بر اساس فراوانی مرتب کنید

دستور زیر واژه‌ها را از پرتکرارترین به کم‌تکرارترین مرتب می‌کند:

```python
ordered = sorted(
    counts,
    key=counts.get,
    reverse=True
)
```

پارامتر `key=counts.get` مشخص می‌کند که ترتیب واژه‌ها بر اساس مقدار ثبت‌شده در دیکشنری باشد. همچنین، `reverse=True` ترتیب نزولی را اعمال می‌کند.

در مرحلهٔ بعد، عبارت `ordered[:n]` تعداد `n` واژهٔ نخست را انتخاب می‌کند. سپس هر واژه همراه با تعداد تکرارش به شکل یک زوج `(word, count)` در فهرست `result` قرار می‌گیرد.

در این تمرین عمداً از کتابخانه‌هایی مانند `Counter` استفاده نمی‌کنیم؛ هدف این است که منطق شمارش و مرتب‌سازی را با حلقه‌ها و دیکشنری به‌خوبی یاد بگیرید.

## ایستگاه سوم — جست‌وجوی واژه، تکمیل برنامه و بررسی مجموعهٔ متنی واقعی

<text color="secondary" size="sm">زمان پیشنهادی: ۱۰ دقیقه</text>

### گام اول: خط‌های حاوی واژهٔ موردنظر را پیدا کنید

در این مرحله، می‌خواهیم تمام خط‌هایی را که یک واژهٔ مشخص در آن‌ها وجود دارد، پیدا کنیم.

کد زیر را در محل مربوط به `TODO-5` قرار دهید:

```python
hits = []

f = open(path, mode="r", encoding="utf-8")

for line in f:
    if word in line:
        hits.append(line.strip())

f.close()

return hits
```

شرط `if word in line` بررسی می‌کند که آیا رشتهٔ موردنظر در خط فعلی وجود دارد یا خیر. اگر چنین باشد، خط با استفاده از `append()` به فهرست نتایج اضافه می‌شود.

متد `strip()` در این مثال، نویسه‌های فاصله و پایان خط را از ابتدا و انتهای خط حذف می‌کند.

این روش نمونه‌ای ساده از جست‌وجوی متنی است: خط‌های منطبق را نگه می‌داریم و بقیه را کنار می‌گذاریم.

برای نمونه، جست‌وجوی واژهٔ `quality` در فایل نمونه باید نتیجهٔ زیر را برگرداند:

```python
['Evaluation measures ranking quality.']
```

### گام دوم: برنامه را به یک ابزار خط فرمان تبدیل کنید

اکنون باید توابع نوشته‌شده را به یک برنامهٔ قابل اجرا از خط فرمان متصل کنیم.

در پایتون، آرگومان‌های ورودی برنامه از طریق `sys.argv` در دسترس هستند. در فایل آغازین این کارگاه، ممکن است آرگومان‌ها ابتدا در متغیری مانند `args` قرار گرفته باشند؛ در این صورت از همان متغیر استفاده کنید.

در این مثال:

* `args[0]` مسیر فایل ورودی است.
* `args[1]`، در صورت ارائه شدن، تعداد واژه‌های پرتکراری است که باید نمایش داده شوند.
* اگر تعداد واژه‌ها مشخص نشود، مقدار پیش‌فرض ۱۰ خواهد بود.

کد مربوط به بخش `TODO-6` را با منطق زیر تکمیل کنید و آن را با ساختار تابع `main()` در فایل آغازین هماهنگ سازید:

```python
path = args[0]

if len(args) > 1:
    n = int(args[1])
else:
    n = 10

stats = count_stats(path)

print("file: " + str(path))
print("lines: " + str(stats["lines"]))
print("words: " + str(stats["words"]))
print("chars: " + str(stats["chars"]))

print("top-" + str(n) + " words:")

for pair in top_words(path, n):
    print("  " + pair[0] + ": " + str(pair[1]))
```

این کد مسیر فایل را دریافت می‌کند، آمار آن را محاسبه می‌کند و سپس واژه‌های پرتکرار را نمایش می‌دهد.

نکته: اگر فایل آغازین از `sys.argv` استفاده می‌کند، مطمئن شوید آرگومان‌ها مطابق ساختار همان فایل استخراج شده‌اند. برای مثال، اگر مستقیماً از `sys.argv` استفاده کنید، نام فایل اسکریپت در اندیس صفر قرار می‌گیرد؛ بنابراین مسیر فایل ورودی در `sys.argv[1]` خواهد بود.

### تمرین اول: مدیریت فایل‌هایی با کدگذاری متفاوت

برنامه را طوری توسعه دهید که هنگام خواندن فایل‌هایی که با UTF-8 سازگار نیستند، بتواند خطا را به‌صورت کنترل‌شده مدیریت کند. برای مثال، می‌توانید از گزینهٔ `errors="replace"` استفاده کنید تا بایت‌های نامعتبر با نویسهٔ جایگزین نمایش داده شوند.

توجه کنید که `errors="replace"` کدگذاری واقعی فایل را تشخیص نمی‌دهد؛ فقط نحوهٔ برخورد با دنباله‌های نامعتبر را هنگام رمزگشایی تعیین می‌کند.

### تمرین دوم: محاسبهٔ آمار کل مجموعهٔ متنی

برنامه را توسعه دهید تا هر ۲۰۴ فایل مجموعهٔ متنی را یکی‌یکی باز کند و واژه‌های تمام اسناد را بشمارد.

در پایان، پرتکرارترین واژه در کل مجموعه را نمایش دهید.

## این مهارت در ادامهٔ دوره چه کاربردی دارد؟

در این کارگاه، ابزاری ساده برای بررسی و تحلیل فایل‌های متنی ساختید. همین ابزار پایه در جلسات بعدی به شما کمک می‌کند داده‌ها را پیش از ورود به مراحل پیچیده‌تر بررسی کنید.

* **جلسهٔ سوم:** از مهارت خواندن و پیمایش فایل برای جست‌وجو در اسناد استفاده خواهید کرد.
* **جلسهٔ پنجم:** متن را به توکن تبدیل می‌کنید و با ساخت نمایهٔ وارونه (Inverted Index)، جست‌وجوی کارآمدتری خواهید ساخت.
* **جلسهٔ هجدهم:** همین مهارت‌ها را در فرایند استخراج و پردازش صفحات وب به کار خواهید گرفت.

در یک خط لولهٔ پردازش داده، ابتدا ورودی را می‌خوانیم، سپس آن را پردازش می‌کنیم و در نهایت نتایج موردنیاز را استخراج می‌کنیم. این کارگاه نخستین تجربهٔ عملی شما از همین الگوست: **فایل را بخوانید، محتوا را بررسی کنید و نتیجه را استخراج کنید.**
